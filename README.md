# ParamX developer docs

The docs site for the ParamX trading API, built with [Mintlify](https://mintlify.com)
and served at docs.paramx.xyz.

- `docs.json`: the site's settings and navigation.
- `*.mdx`, `api/*.mdx`: the pages.

Preview locally with `npx mint dev`, and check links with `npx mint broken-links`.
Pushing to `main` publishes the site (through Mintlify's GitHub app).
